# ComfyUI-CompareImagesFixed
This allows the 'Compare Images' node—which is supported only in Node 2.0—to be used in Node 1.0 as well.

# function
- The core functionality remains the same.
- I removed the "slide" button that was previously located in the middle of the base node, as I found it intrusive.
- I updated the implementation so that a slide can be initiated naturally in any direction—up, down, left, or right.
